📖 8차시: 나머지 연산자(%)로 색깔 순환하기

1. 나눈 나머지 구하기 (%) ➗

%는 나눗셈을 하고 남은 나머지만 알려주는 기호예요. 7 % 3은 7을 3으로 나누면 2가 남으니까 결과는 2랍니다!

print(7 % 3)

2. 나머지는 항상 같은 숫자들만 반복돼요 🔄

어떤 숫자든 % 3을 하면 결과는 무조건 0, 1, 2 중 하나예요. 그래서 i % 3은 i가 아무리 커져도 0→1→2→0→1→2... 처럼 계속 순환한답니다!

i % 3

3. 리스트 칸 번호로 딱 맞게 사용하기 🎯

7차시에서 배운 리스트는 딱 정해진 칸 수만 있죠? colors가 3칸짜리 리스트라면, i % 3을 인덱스로 쓰면 리스트를 벗어나지 않고 색깔을 무한히 순환시킬 수 있어요!

t.color(colors[i % 3])

4. 반복문과 함께 색깔 기차 만들기 🚂

for문 안에서 i가 0, 1, 2, 3...으로 계속 바뀌니까, colors[i % 3]을 쓰면 도장을 찍을 때마다 색깔이 자동으로 순서대로 바뀌어요!

for i in range(9): t.color(colors[i % 3]) t.stamp()
