📖 19차시: 마우스 마법 그림판

1. 마우스로 드래그하기 (ondrag) 🖱️

ondrag 마법을 쓰면 마우스를 꾹 누른 채로 움직일 때 거북이가 마우스를 따라오게 만들 수 있어요!

t.ondrag(t.goto)

2. 마우스 클릭 감지하기 (onscreenclick) 👆

화면의 빈 곳을 클릭했을 때 특정 행동을 하게 하려면 onscreenclick을 사용합니다.

turtle.onscreenclick(t.goto)

3. 낙서장 싹 지우기 (clear) 🧽

그림판이 너무 지저분해졌나요? clear() 마법 한 방이면 내가 그린 선들이 모두 깨끗하게 지워져요.

t.clear()

4. 단축키로 색깔 바꾸기 🎨

키보드의 특정 키(예: 'r')를 누르면 색이 변하도록 함수를 만들어서 연결해 볼 거예요.

def color_red(): t.color("red")
