📖 18차시: 진정한 스네이크 (꼬리 성장)

1. 꼬리가 길어지는 마법 🟩

먹이를 먹을 때마다 새로운 네모 거북이를 만들어서 리스트 맨 뒤에 추가(`append`)해 주면 꼬리가 길어져요!

snakes.append(new_body)

2. 리스트의 길이 재기 (len) 📏

꼬리가 길어졌으니 앞 꼬리 따라가기 `for`문도 바뀌어야 해요. `len(snakes)`는 뱀 몸통이 총 몇 개인지 숫자로 알려줍니다!

for i in range(len(snakes)-1, 0, -1):

3. 벽에 쿵! (게임 오버) 💥

뱀의 머리(`snakes[0]`)가 화면 끝(280)을 넘어가면 게임이 끝나는 로직을 만듭니다.

if snakes[0].xcor() > 280: return

4. 내 몸을 깨물면 안 돼! (슬라이싱) 😱

snakes[1:]은 머리(0번)를 뺀 나머지 모든 몸통을 의미해요. 몸통 중 하나라도 머리와 부딪혔는지 검사합니다!

for body in snakes[1:]: if snakes[0].distance(body) < 10: return
