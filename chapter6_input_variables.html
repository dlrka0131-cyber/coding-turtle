📖 6차시: 거북이와 대화하기 (변수와 입력)

1. 변수 상자에 값 담기 📦

변수는 데이터를 담아두는 이름표가 붙은 상자예요. name이라는 변수에 글자를 담아볼까요?

name = "거북이"

2. 사용자에게 질문하기 (textinput) 💬

컴퓨터가 화면 창을 띄워 사용자에게 직접 글자를 입력받을 수 있어요.

answer = turtle.textinput("질문", "이름이 뭐니?")

3. 숫자로 바꾸기 (int 형변환) 🔢

입력받은 값은 기본적으로 '글자(문자열)'로 취급돼요. 숫자로 계산하려면 int()로 감싸주어야 해요!

num = int(turtle.textinput("숫자", "몇 칸 갈까?"))

4. 변수를 활용해 이동하기 🐾

상자(변수) 안에 들어있는 숫자를 꺼내서 거북이의 이동 거리에 그대로 사용할 수 있어요.

t.forward(num)

5. 결과 화면에 출력하기 (print) 🖨️

아래쪽 결과창에 변수 안에 든 값을 출력해서 확인할 수 있어요.

print(answer)
