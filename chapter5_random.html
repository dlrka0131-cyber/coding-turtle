📖 5차시: 랜덤(Random)과 좌표(x, y)!

1. 랜덤 기능 불러오기 🎲

파이썬에서 무작위(랜덤) 기능을 사용하려면 random을 먼저 불러와야 해요.

import random

2. 랜덤 위치(좌표) 뽑기 📍

randint(-200, 200)은 -200부터 200 사이의 아무 숫자나 하나 뽑아준다는 뜻이에요.

x = random.randint(-200, 200)

3. 특정 좌표로 이동하기 (goto) 🚀

거북이에게 직접 어느 위치로 가라고 명령할 땐 goto(x, y)를 써요. 방금 뽑은 x 위치로 가볼까요?

t.goto(x, 100)

4. 거북이 도장 찍기 (stamp) 🐾

거북이가 현재 있는 위치에 자기 모양과 똑같은 도장을 쾅! 찍고 싶을 때 사용해요.

t.stamp()

5. 마우스 따라가기 🖱️

onscreenclick을 사용하면, 화면을 클릭할 때마다 그 좌표로 거북이가 이동한답니다!

turtle.onscreenclick(t.goto)
