📖 15차시: 술래잡기 (타이머와 추적)

1. 목표물 좌표 바라보기 (towards) 🎯

towards(x, y)는 거북이가 x, y 좌표가 있는 쪽의 각도를 계산해 줘요. 10차시에서 배운 xcor(), ycor()를 활용해서 내 거북이(t)의 위치를 짚어주면 적이 고개를 휙! 돌립니다.

enemy.setheading(enemy.towards(t.xcor(), t.ycor()))

2. 타이머로 자동 반복 (ontimer) ⏱️

for문 없이도 스스로 움직이게 하려면 ontimer(함수이름, 밀리초)를 써요. 100밀리초(0.1초) 뒤에 함수를 다시 부르라는 뜻이에요.

turtle.ontimer(chase, 100)

3. 계속 실행되는 타이머 마법 🔁

함수 마지막 줄에서 ontimer로 자기 자신을 다시 예약하면, 마치 알람이 울릴 때마다 다음 알람을 새로 맞추는 것처럼 프로그램이 끝날 때까지 멈추지 않고 계속 실행된답니다!

def chase(): enemy.forward(5) turtle.ontimer(chase, 100)

4. 잡혔다! 게임 오버 종료하기 🛑

술래와 나의 거리가 가까워지면(충돌), 타이머를 다시 부르지 않고 그 자리에서 return을 써서 끝내버려요!

if t.distance(enemy) < 20: return
